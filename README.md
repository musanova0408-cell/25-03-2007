# Колледж кітапханасы

## Жоба туралы
Колледж кітапханасы — кітаптарды қарауға, іздеуге және кітапхана қорын басқаруға арналған веб-сайт.

## Негізгі мүмкіндіктері
- Кітаптар тізімін көру
- Кітаптарды іздеу
- Кітаптар туралы ақпарат қарау
- Оқырмандарды басқару
- Әкімші панелін пайдалану

## Қолданылған технологиялар
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Apache
- Docker

## Жобаны іске қосу
1. Жобаны GitHub репозиторийінен жүктеп алыңыз.
2. XAMPP бағдарламасын іске қосыңыз.
3. Жоба бумасын `C:\xampp\htdocs\college-library` ішіне орналастырыңыз.
4. Apache және MySQL қызметтерін іске қосыңыз.
5. Қажетті дерекқорды phpMyAdmin арқылы жасаңыз.
6. Браузерден `http://localhost/college-library/` мекенжайын ашыңыз.

## Docker арқылы іске қосу
Docker Desktop бағдарламасы орнатылған болуы керек.

Image құру:
```bash
docker build -t college-library .
```

Контейнерді іске қосу:
```bash
docker run -d -p 8080:80 --name college-library-app college-library
```

Сайтты ашу:
`http://localhost:8080`

Контейнерді тоқтату:
```bash
docker stop college-library-app
```

Контейнерді қайта іске қосу:
```bash
docker start college-library-app
```
